## Milestone Summary

**Key Decisions:**

- Cloudflare Tunnel uses remote-managed ingress (API) — local config.yml ingress is ignored since cloudflared 2026.3.0; all tunnel additions must use the Cloudflare API
- Non-root migration: all 4 GitHub Actions deploy workflows deleted permanently; manual deploy only (no HETZNER_SSH_KEY stored on GitHub)
- CLAUDE.md-first automation: server-side `maybeStartVerify` trigger removed; verify-work is now user/CLAUDE.md-driven, not server-injected
- pm2-logrotate is the PM2 log management solution (not logrotate system daemon); PM2-managed processes don't interact cleanly with system logrotate
- Disk prevention: PM2 is sole log sink for cloudflared (tee removed); startup truncation guard prevents stale log carry-over on PM2 restart

**Issues Resolved:**

- Railway $120/month → Hetzner €5/month (96% cost reduction)
- Claude Code `--dangerously-skip-permissions` blocked for root since 2.1.126 → fixed by claude OS user
- Disk full → 502 outage pattern → fixed by log rotation + monitoring + pruning
- Server-side auto-verify injection causing unexpected GSD command firing → removed

**Issues Deferred:**

- Version-control `/home/services/hetzner-vps/` docker-compose.yml (no git history = no rollback) — captured as pending todo
- Volume Storage page for GSD Dashboard — captured as pending todo

**Technical Debt Incurred:**
