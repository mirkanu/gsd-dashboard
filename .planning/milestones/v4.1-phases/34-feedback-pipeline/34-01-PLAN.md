      id INTEGER PRIMARY KEY AUTOINCREMENT,
      message_id INTEGER NOT NULL,

      hit_count INTEGER NOT NULL DEFAULT 0,

      FOREIGN KEY (feedback_id) REFERENCES classifier_feedback(id) ON DELETE SET NULL
    );
    CREATE INDEX IF NOT EXISTS idx_overrides_enabled ON classifier_overrides(enabled, priority DESC);

**2. Create server/gsd/patternManager.js** following the architecture doc exactly:

- Import `classifyLine` from `./classifierPatterns` as `staticClassifyLine`
- Import `strip-ansi` (already a project dependency)
- Class `PatternManager`:
  - Constructor takes `db` (the raw better-sqlite3 instance), calls `loadOverrides()`
  - `loadOverrides()`: reads all enabled overrides from DB, compiles each `pattern` string into a RegExp, stores as `this.overrides` array sorted by priority DESC, id DESC
  - `classifyLine(rawLine)`: strips ANSI, trims. Tier 1: iterate `this.overrides`, first regex match returns `{ msg_type: override.target_type, content: clean, metadata: null }` and bumps hit_count (non-blocking). Tier 2+3: delegate to `staticClassifyLine(rawLine)` (which handles static patterns + default to text)
  - `classifyChunks(rawText)`: splits on newline, maps through `classifyLine`, filters null
  - `addOverride(pattern, targetType, feedbackId)`: inserts to DB, prepends to in-memory array with compiled regex, returns new override ID
  - `disableOverride(id)`: sets enabled=0 in DB, removes from in-memory array
  - `findExistingOverride(content, targetType)`: checks if any override already matches content with same target type
  - `findConflictingOverride(content, targetType)`: checks if any override matches content with a DIFFERENT target type
  - `derivePattern(content)`: static method. Takes first line, escapes regex special chars, truncates to 40 chars, anchors to `^`. Returns the regex string.

Export: `{ PatternManager }`

Use `db.prepare(...)` directly in PatternManager (not stmts) for the hit_count bump since it's a hot-path optimization. For loadOverrides, use a fresh prepare call (not stmts.listOverrides) to keep PatternManager self-contained.

**1. Add feedback + override endpoints to server/routes/gsd.js:**

Import `MESSAGE_TYPES` from `../gsd/classifierPatterns` at the top for validation.

Add these routes after the existing task routes:

**POST /api/gsd/messages/:id/feedback** (the core feedback endpoint):
- Request body: `{ correct_type: string }`
- Validate `correct_type` is a value in MESSAGE_TYPES (use `Object.values(MESSAGE_TYPES).includes(correct_type)`)
- Fetch message via `stmts.getGsdMessage.get(id)` -- 404 if not found
- If `correct_type === message.message_type`, return `{ ok: true, message: 'No change needed' }` (no-op)
- Insert feedback: `stmts.insertFeedback.run(id, message.message_type, correct_type, message.content)`
- Get patternManager from `req.app.locals.patternManager`
- Derive pattern: `PatternManager.derivePattern(message.content)` (import PatternManager for static method)
- Check for existing override with same content+type: `patternManager.findExistingOverride(message.content, correct_type)` -- if found, skip override creation
- Check for conflicting override: `patternManager.findConflictingOverride(message.content, correct_type)` -- if found, `patternManager.disableOverride(conflict.id)`
- If no existing override found, create: `patternManager.addOverride(pattern, correct_type, feedbackId)`
- Update message type: `stmts.updateMessageType.run(correct_type, id)`
- Broadcast via websocket: `req.app.locals.broadcast('gsd_message_updated', { project: message.project, message: { ...message, message_type: correct_type } })`
- Return `{ ok: true, override_id, message: { id, message_type: correct_type } }`
- Wrap everything in try/catch, return 500 on error
- Add GSD_DATA_URL proxy passthrough at the top (same pattern as other routes)

**GET /api/gsd/classifier/feedback** (feedback history):
- Query params: `limit` (default 50, max 200), `offset` (default 0)
- Returns `{ feedback: stmts.listFeedback.all(limit, offset) }`
- Add GSD_DATA_URL proxy passthrough

**GET /api/gsd/classifier/overrides** (active overrides):
- Returns `{ overrides: stmts.listOverrides.all() }`
- Add GSD_DATA_URL proxy passthrough

**DELETE /api/gsd/classifier/overrides/:id** (disable override):
- Get patternManager from `req.app.locals.patternManager`
- Call `patternManager.disableOverride(parseInt(id))`
- Return `{ ok: true }`
- Add GSD_DATA_URL proxy passthrough
