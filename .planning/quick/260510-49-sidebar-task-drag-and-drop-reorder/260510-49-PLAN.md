# Quick Task 260510-49: Sidebar Task Drag-and-Drop Reorder

## Tasks

### Task 1: DB migration — add sort_order column
- **File:** `server/db.js`
- **Action:** Add `sort_order INTEGER NOT NULL DEFAULT 0` column to `project_tasks`; backfill based on creation order; update `listTasks` to order by `sort_order ASC, created_at ASC`; add `updateTaskSortOrder` prepared statement

### Task 2: Backend reorder endpoint
- **File:** `server/routes/gsd.js`
- **Action:** Add `PATCH /api/gsd/projects/:key/tasks/reorder` accepting `{ ids: number[] }`, updating sort_order in a transaction. Register before `/:id` to avoid route collision.

### Task 3: Frontend drag-and-drop
- **Files:** `client/src/lib/types.ts`, `client/src/lib/api.ts`, `client/src/components/TasksTab.tsx`
- **Action:** Add `sort_order?` to `GsdTask`; add `reorder()` to api tasks; add `GripVertical` drag handle to `TaskRow`; manage drag state in `TasksTab`; optimistic reorder with revert on failure
