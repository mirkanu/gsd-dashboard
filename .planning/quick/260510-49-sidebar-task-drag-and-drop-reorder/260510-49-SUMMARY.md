# Quick Task 260510-49: Sidebar Task Drag-and-Drop Reorder

## What was done

Added drag-and-drop reordering to the project tasks sidebar (TasksTab).

**DB:** Added `sort_order` column to `project_tasks` via migration with backfill. `listTasks` now orders by `sort_order ASC, created_at ASC`.

**Backend:** `PATCH /api/gsd/projects/:key/tasks/reorder` accepts `{ ids: number[] }` and updates sort_order in a SQLite transaction. Registered before `/:id` to prevent route collision.

**Frontend:** `GripVertical` handle on each open task row; HTML5 drag-and-drop with `onDragStart`/`onDragOver`/`onDrop`; optimistic state update; API call to persist order; revert on failure. Archived tasks don't show the handle and aren't draggable.

## Files changed
- `server/db.js` — migration + updated listTasks query + updateTaskSortOrder stmt
- `server/routes/gsd.js` — /reorder endpoint
- `client/src/lib/types.ts` — sort_order?: number on GsdTask
- `client/src/lib/api.ts` — tasks.reorder()
- `client/src/components/TasksTab.tsx` — drag handle + drag state + handlers
