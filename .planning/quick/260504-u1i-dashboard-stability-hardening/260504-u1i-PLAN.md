**scripts/tmux-save.sh:**
Saves current tmux state to `~/.tmux-sessions` (one file per session). Steps:
1. Check `tmux list-sessions 2>/dev/null` — exit 0 silently if no server running.
2. Create `~/.tmux-sessions/` if it does not exist.
3. For each session name from `tmux list-sessions -F '#{session_name}'`:
   - Save window list: `tmux list-windows -t "$session" -F '#{window_index} #{window_name} #{pane_current_path}' > ~/.tmux-sessions/"$session".windows`
4. Write a session index: `tmux list-sessions -F '#{session_name}' > ~/.tmux-sessions/sessions.list`
5. Log timestamp to `~/.tmux-sessions/last-save`: `echo "$(date -Iseconds)" > ~/.tmux-sessions/last-save`

```bash
#!/usr/bin/env bash
set -euo pipefail
SAVE_DIR="$HOME/.tmux-sessions"
mkdir -p "$SAVE_DIR"

if ! tmux list-sessions &>/dev/null; then
  echo "tmux-save: no sessions running, skipping." >&2
  exit 0
fi

tmux list-sessions -F '#{session_name}' > "$SAVE_DIR/sessions.list"

while IFS= read -r session; do
  tmux list-windows -t "$session" \
    -F '#{window_index} #{window_name} #{pane_current_path}' \
    > "$SAVE_DIR/${session}.windows" 2>/dev/null || true
done < "$SAVE_DIR/sessions.list"

date -Iseconds > "$SAVE_DIR/last-save"
echo "tmux-save: saved $(wc -l < "$SAVE_DIR/sessions.list") sessions at $(cat "$SAVE_DIR/last-save")"
```

**scripts/tmux-restore.sh:**
Reads `~/.tmux-sessions/sessions.list` and recreates missing sessions. Sessions that already exist are skipped (idempotent).

```bash
#!/usr/bin/env bash
set -euo pipefail
SAVE_DIR="$HOME/.tmux-sessions"

if [[ ! -f "$SAVE_DIR/sessions.list" ]]; then
  echo "tmux-restore: no saved sessions found at $SAVE_DIR/sessions.list" >&2
  exit 0
fi

restored=0
while IFS= read -r session; do
  [[ -z "$session" ]] && continue
  # Skip if session already exists
  if tmux has-session -t "$session" 2>/dev/null; then
    echo "tmux-restore: session '$session' already exists, skipping."
    continue
  fi
  # Determine start directory from first window entry if available
  start_dir="$HOME"
  win_file="$SAVE_DIR/${session}.windows"
  if [[ -f "$win_file" ]]; then
    first_path=$(awk 'NR==1{print $3}' "$win_file")
    [[ -d "$first_path" ]] && start_dir="$first_path"
  fi
  tmux new-session -d -s "$session" -c "$start_dir"
  echo "tmux-restore: created session '$session' in $start_dir"
  ((restored++)) || true
done < "$SAVE_DIR/sessions.list"

echo "tmux-restore: restored $restored session(s)."
```

  <name>Task 3: Memory guard script + PM2 registration</name>
  <files>scripts/memory-guard.sh</files>
  <action>
Create `/home/services/gsddashboard/scripts/memory-guard.sh` (executable). The script:

1. Reads available RAM from `/proc/meminfo` (`MemAvailable` line in kB).
2. Converts to MB. If below 400MB threshold, logs a WARNING.
3. Finds `node --test` processes running longer than 10 minutes and kills them (they are always hung if they have been alive that long).
4. Logs everything to `/home/claude/.pm2/logs/memory-guard.log`.
5. If a hung process is owned by root and the current user is `claude`, logs a warning that `sudo kill` would be needed rather than silently failing.

```bash
#!/usr/bin/env bash
# memory-guard.sh — checks RAM pressure and kills hung node --test processes
# Logs to /home/claude/.pm2/logs/memory-guard.log

set -euo pipefail

LOG_FILE="/home/claude/.pm2/logs/memory-guard.log"
THRESHOLD_MB=400
MAX_TEST_MINUTES=10

log() {
  echo "[$(date -Iseconds)] $*" >> "$LOG_FILE"
}

# Ensure log directory exists
mkdir -p "$(dirname "$LOG_FILE")"

# ── 1. Check available RAM ────────────────────────────────────────────────────
avail_kb=$(grep '^MemAvailable:' /proc/meminfo | awk '{print $2}')
avail_mb=$(( avail_kb / 1024 ))

if (( avail_mb < THRESHOLD_MB )); then
  log "WARNING: Available RAM is ${avail_mb}MB (below ${THRESHOLD_MB}MB threshold). OOM risk."
else
  log "INFO: RAM OK — ${avail_mb}MB available."
fi

# ── 2. Kill hung node --test processes older than MAX_TEST_MINUTES ────────────
hung_pids=$(ps -eo pid,etimes,user,args --no-headers \
  | awk -v max=$(( MAX_TEST_MINUTES * 60 )) \
    '$2 >= max && $4 == "node" && $5 == "--test" {print $1, $3, $4, $5}' \
  || true)

if [[ -z "$hung_pids" ]]; then
  log "INFO: No hung node --test processes found."
else
  log "WARNING: Found hung node --test process(es):"
  while IFS= read -r line; do
    pid=$(echo "$line" | awk '{print $1}')
    owner=$(echo "$line" | awk '{print $2}')
    log "  PID=$pid owner=$owner"
    if [[ "$owner" == "root" ]] && [[ "$(whoami)" != "root" ]]; then
      log "  NOTICE: PID $pid is owned by root — run 'sudo kill $pid' manually to terminate."
    else
      if kill "$pid" 2>/dev/null; then
        log "  Killed PID $pid (owner=$owner)."
      else
        log "  Failed to kill PID $pid (owner=$owner) — may need sudo."
      fi
    fi
  done <<< "$hung_pids"
fi
```
