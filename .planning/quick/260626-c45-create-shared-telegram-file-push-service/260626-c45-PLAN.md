  <name>Task 1: Add sendFileDocument to shared telegram module</name>
  <files>server/gsd/telegram.js</files>
  <action>
Add a `sendFileDocument(filePath, caption)` function to `server/gsd/telegram.js` that sends a local file as a Telegram document using the Bot API's `sendDocument` method.

Requirements:
- Uses `fetch` with `FormData` (no external dependency) — append the file as a readable stream via `fs.createReadStream(filePath)`
- Reuses the existing `BOT_TOKEN`, `CHAT_ID`, `ENABLED`, and `API_BASE` constants already defined in the module
- Returns early if `!ENABLED` (same guard as `sendNotification`)
- Truncates caption to Telegram's 1024-char limit if provided
- Logs success/failure to console with `[telegram]` prefix (matching existing convention)
- Export `sendFileDocument` alongside existing exports

Implementation pattern:
```js
async function sendFileDocument(filePath, caption) {
  if (!ENABLED) return;
  try {
    const fs = require('fs');
    const formData = new FormData();
    formData.append('chat_id', CHAT_ID);
    formData.append('document', fs.createReadStream(filePath));
    if (caption) formData.append('caption', caption.slice(0, 1024));
    const res = await fetch(`${API_BASE}/sendDocument`, { method: 'POST', body: formData });
    const data = await res.json();
    if (!data.ok) console.error('[telegram] sendDocument failed:', data.description);
    else console.log(`[telegram] File sent: ${filePath}`);
  } catch (err) {
    console.error('[telegram] sendDocument error:', err.message);
  }
}
```

Add to the existing `module.exports` at the bottom of the file.

Create `server/routes/telegram.js` — a new Express router exposing `POST /api/telegram/send-file`.

Request body (JSON):
```json
{
  "filePath": "/absolute/path/to/file",
  "caption": "Optional caption text"
}
```

Validation:
- `filePath` must be a non-empty string — return 400 if missing
- `filePath` must exist on disk (`fs.existsSync`) — return 404 if not found
- Resolve the path and ensure it stays within `/home/services/` (prevent path traversal — reject if resolved path does not start with `/home/services/`)

On success: call `sendFileDocument(filePath, caption)` and return 200 `{ ok: true }`.
On error from telegram: return 502 `{ error: 'telegram_failed' }`.

Mount in `server/index.js` by adding:
```js
const telegramRouter = require('./routes/telegram');
app.use('/api/telegram', telegramRouter);
```

Place this after the existing `app.use("/api/upload", uploadRouter)` line to keep route registration grouped together.
