# Quick Task 260626-c45: Shared Telegram File Push Service Summary

Added a `sendFileDocument` function and `POST /api/telegram/send-file` endpoint so any project on the VPS can push files to the user's Telegram chat as documents.

## What was built

1. **`sendFileDocument(filePath, caption)`** in `server/gsd/telegram.js` — sends a local file as a Telegram document using `fetch` + `FormData` + `fs.createReadStream`. Reuses existing `BOT_TOKEN`, `CHAT_ID`, `ENABLED`, `API_BASE` constants. Truncates caption to Telegram's 1024-char limit.

2. **`POST /api/telegram/send-file`** in `server/routes/telegram.js` — accepts `{ filePath, caption? }`, validates input, prevents path traversal (restricts to `/home/services/`), checks file existence, delegates to `sendFileDocument`. Returns structured errors (400/403/404/502).
