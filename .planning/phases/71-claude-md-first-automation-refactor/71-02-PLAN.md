**Verification backstop (D-05 Phase 71):**

Before closing, check whether the most recently executed phase has a verification record.

Identify the most recent executed phase:
```bash
# Extract the highest phase number that has at least one SUMMARY.md
MOST_RECENT_PHASE=$(ls -d .planning/phases/[0-9]*-*/ 2>/dev/null | \
  while read d; do
    phase_num=$(basename "$d" | grep -o '^[0-9]*')
    summary_count=$(ls "$d"*-SUMMARY.md 2>/dev/null | wc -l)
    [ "$summary_count" -gt 0 ] && echo "$phase_num"
  done | sort -n | tail -1)
```

Check whether a UAT.md exists for that phase:
```bash
if [ -n "$MOST_RECENT_PHASE" ]; then
  PADDED=$(printf '%02d' "$MOST_RECENT_PHASE")
  PHASE_DIR=$(ls -d .planning/phases/${PADDED}-*/ 2>/dev/null | head -1)
  UAT_FILE=$(ls "${PHASE_DIR}"*-UAT.md 2>/dev/null | head -1)
  if [ -z "$UAT_FILE" ]; then
    echo "WARN: Phase ${MOST_RECENT_PHASE} has no verification record (no UAT.md found)."
  fi
fi
```
