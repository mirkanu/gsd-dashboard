  <action>
Run the following commands in order. Each must succeed before proceeding to the next.

```bash
# Step 1: Install the pm2-logrotate module
pm2 install pm2-logrotate

# Step 2: Configure rotation policy (D-03)
pm2 set pm2-logrotate:max_size 20M
pm2 set pm2-logrotate:retain 3
pm2 set pm2-logrotate:compress true
pm2 set pm2-logrotate:dateFormat YYYY-MM-DD_HH-mm-ss
pm2 set pm2-logrotate:rotateInterval '0 0 * * *'

# Step 3: Persist configuration across reboots
pm2 save
```

If `pm2 install pm2-logrotate` fails with a permission error, try: `pm2 install pm2-logrotate --no-save` then run `pm2 save` manually after configuration.

After install, verify the module appears in `pm2 list` output.
