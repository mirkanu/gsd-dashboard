# Plan 68-01: Install Portainer CE + Expose via Cloudflare Tunnel

## Goal

Run Portainer CE as a Docker container on the Hetzner VPS and expose it at `portainer.gsdlabs.dev`
via the existing named Cloudflare Tunnel.

## Context

- VPS: `claude@37.27.212.18` via `~/.ssh/hetzner_claude`
- Docker socket: `/var/run/docker.sock`
- Cloudflare Account: `04bc84539b1073de92780f3c7568d273`, Tunnel: `093489ad-5644-4b42-a6c6-32c45c244fed`
- Tunnel uses remote-managed ingress (API, not local YAML) — learned from Phase 67
- Use Portainer CE HTTP port 9000 (avoids self-signed cert complexity with tunnel)

## Tasks

### Task 1 — Run Portainer CE container

<read_first>
- `docker ps | grep portainer` — confirm not already running
</read_first>

<action>
Create a named Docker volume and start Portainer CE:

```bash
docker volume create portainer_data

docker run -d \
  --name portainer \
  --restart=always \
  -p 9000:9000 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v portainer_data:/data \
  portainer/portainer-ce:latest
```

Verify it started:
```bash
docker ps | grep portainer
curl -s http://localhost:9000/ | grep -i portainer
```
</action>

<acceptance_criteria>
- `docker ps | grep portainer` shows portainer running
- `curl -s http://localhost:9000/` returns Portainer HTML (not connection refused)
</acceptance_criteria>

### Task 2 — Add portainer.gsdlabs.dev DNS CNAME

<read_first>
- Cloudflare API credentials: CLOUDFLARE_API_KEY and CLOUDFLARE_EMAIL from /home/services/.env.production
</read_first>

<action>
Add CNAME record via Cloudflare API:

```bash
ZONE_ID=6c322a054d869df9450e4c99e8d4d4a8
CF_EMAIL=manuelkuhs@gmail.com
CF_KEY=c13f97a1878e5e8890de21df58f770e403cd1
TUNNEL_ID=093489ad-5644-4b42-a6c6-32c45c244fed

curl -s -X POST "https://api.cloudflare.com/client/v4/zones/$ZONE_ID/dns_records" \
  -H "X-Auth-Email: $CF_EMAIL" \
  -H "X-Auth-Key: $CF_KEY" \
  -H "Content-Type: application/json" \
  --data "{
    \"type\": \"CNAME\",
    \"name\": \"portainer.gsdlabs.dev\",
    \"content\": \"$TUNNEL_ID.cfargotunnel.com\",
    \"proxied\": true,
    \"ttl\": 1
  }"
```
</action>

<acceptance_criteria>
- API response contains `"success": true` and `"name": "portainer.gsdlabs.dev"`
</acceptance_criteria>
