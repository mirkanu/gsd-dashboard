  <action>
In `client/src/components/TasksTab.tsx`, replace the description `<input type="text">` (around line 171) with a `<textarea>` that auto-grows:

1. Replace the `<input>` element with `<textarea>`:
```tsx
<textarea
  placeholder="Description (optional)"
  value={description}
  rows={1}
  onChange={(e) => {
    setDescription(e.target.value);
    // Auto-grow: reset height then set to scrollHeight
    e.target.style.height = "auto";
    e.target.style.height = `${e.target.scrollHeight}px`;
  }}
  className="w-full bg-surface-3 border border-border rounded px-3 py-1.5 text-sm text-gray-200 placeholder-gray-600 focus:outline-none focus:border-accent resize-none overflow-y-auto"
  style={{ maxHeight: "10rem" }}
/>
```

Key details:
- `rows={1}` starts the textarea at a single line height (matching the old input visually)
- `resize-none` prevents manual browser resize handle (ugly in dark UI)
- `overflow-y-auto` enables scrolling once max-height is reached
- `style={{ maxHeight: "10rem" }}` caps growth at ~6 lines (~160px)
- The `onChange` handler resets `height` to `"auto"` first so the element can shrink when text is deleted, then sets it to `scrollHeight` to fit content exactly
- Do NOT use `useRef` — the inline handler on the event target is sufficient and avoids complexity

2. When editing an existing task (`handleEdit` loads description into state), the textarea will not auto-size on mount since the onChange trick requires user input. Fix this with a `useEffect` that resets textarea height when `editingTask` changes:

Add a ref for the textarea:
```tsx
import { useState, useEffect, useRef } from "react";
// ...
const descRef = useRef<HTMLTextAreaElement>(null);
```

Add a useEffect after the existing effects:
```tsx
useEffect(() => {
  if (descRef.current) {
    descRef.current.style.height = "auto";
    descRef.current.style.height = `${descRef.current.scrollHeight}px`;
  }
}, [description]);
```

Add `ref={descRef}` to the textarea element.

3. No other changes to the file. Keep all existing logic (form submit, archive, unarchive, copy, edit flow) intact.
