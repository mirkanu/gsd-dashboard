```tsx
        {/* Docker space breakdown — D-01, D-03 */}
        <div className="border-t">
          <div className="px-4 py-2 text-xs font-medium text-muted-foreground uppercase tracking-wide">
            Docker
          </div>
          {dockerDf === null ? (
            <div className="px-4 py-2 text-sm text-muted-foreground italic">Loading...</div>
          ) : dockerDf.error ? (
            <div className="px-4 py-2 text-sm text-muted-foreground italic">unavailable</div>
          ) : (
            <div className="grid grid-cols-2 gap-x-4 px-4 pb-3">
              {dockerDf.entries.map((entry) => {
                // Parse reclaimable MB to check amber threshold
                const reclaimStr = entry.reclaimable ?? "";
                const gbMatch = reclaimStr.match(/([\d.]+)\s*GB/i);
                const mbMatch = reclaimStr.match(/([\d.]+)\s*MB/i);
                const reclaimMb = gbMatch
                  ? parseFloat(gbMatch[1]) * 1024
                  : mbMatch
                  ? parseFloat(mbMatch[1])
                  : 0;
                const isBuildCache = entry.type === "Build Cache";
                const isAmber = isBuildCache && reclaimMb > 5120;
                return (
                  <div key={entry.type} className="py-1.5">
                    <div className="text-xs text-muted-foreground">{entry.type}</div>
                    <div className="text-sm font-medium tabular-nums">{entry.size}</div>
                    <div className={`text-xs tabular-nums ${isAmber ? "text-amber-400" : "text-muted-foreground"}`}>
                      {entry.reclaimable} reclaimable
                    </div>
                  </div>
                );
              })}
            </div>
          )}
        </div>
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /system/docker-df | Read-only fetch; no user input sent to backend |
| browser → /system/oom-status | Read-only fetch; no user input sent to backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-73-05 | Information Disclosure | DockerDf response in browser | accept | Dashboard is single-user, cookie-auth gated at Express middleware. Docker disk info is operational data, not secrets. |
| T-73-06 | Spoofing | reclaimable string parsing in client | accept | String is parsed for display threshold only — no security decision is made from the value. Worst case: amber highlight is wrong. |
| T-73-07 | Denial of Service | dockerDf fetch failure | mitigate | `.catch(() => {})` silently leaves `dockerDf` as `null`; UI shows "Loading..." indefinitely rather than crashing. Endpoint itself has 5s execSync timeout. |
</threat_model>
