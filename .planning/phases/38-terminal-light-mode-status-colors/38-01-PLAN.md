**Fix 1 — xterm selectionBackground (TERM-03):**
Update `TERM_THEMES.light` to include `selectionBackground`. The xterm Terminal constructor receives `theme: { background, foreground }` — add `selectionBackground` to both the type and the object.

Change `TERM_THEMES.light` from:
```typescript

```
To:
```typescript
light: { background: '#f5f5f5', foreground: '#24292e', selectionBackground: 'rgba(99, 102, 241, 0.35)', overlay: 'rgba(255,255,255,0.92)', overlayText: 'rgba(245,245,245,0.95)' },
```

Also update `TERM_THEMES.dark` to include a matching selectionBackground for parity:
```typescript
dark:  { background: '#0d1117', foreground: '#c9d1d9', selectionBackground: 'rgba(99, 102, 241, 0.4)', overlay: 'rgba(0,0,0,0.9)', overlayText: 'rgba(13,17,23,0.92)' },
```

Then update the Terminal constructor call to pass `selectionBackground` in the theme:
```typescript
const terminal = new Terminal({

  fontSize: ...,
  fontFamily: ...,
  theme: {
    background: tt.background,
    foreground: tt.foreground,
    selectionBackground: tt.selectionBackground,
  },
});
```

- The "Paste" button: change `hover:text-white` → `hover:text-gray-900`
- The "Select"/"Done" button: change `hover:text-white` → `hover:text-gray-900`
- The info button (onInfo): change `hover:text-white` → `hover:text-gray-900`
- The close button: change `hover:text-white` → `hover:text-gray-900`
