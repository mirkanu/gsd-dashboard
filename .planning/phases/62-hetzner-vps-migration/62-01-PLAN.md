SSH into the VPS as root using the IP collected in the checkpoint above.
Run the following bootstrap sequence (one SSH session, sequential commands):

```bash
# 1. Update OS
apt-get update && apt-get upgrade -y

# 2. Install Docker (official script — Debian 12)
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh
# No usermod needed — running as root

# 3. Verify Docker + Compose
docker --version          # Must be 24.0.7+
docker compose version    # Must be v2.24+

# 4. Install Node.js 20 LTS (for PM2)
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs
node --version   # Must be v20.x

# 5. Install PM2 globally
npm install -g pm2
pm2 --version    # Confirm installed

# 6. Install cloudflared (Debian ARM64 package)
curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64.deb -o cloudflared.deb
dpkg -i cloudflared.deb
cloudflared --version    # Confirm installed

# 7. Install git and curl (usually pre-installed on Debian 12, confirm)
apt-get install -y git curl

# 8. Create service directory layout
mkdir -p /home/services/hetzner-vps
mkdir -p /home/services/gsddashboard
mkdir -p /home/services/debates
mkdir -p /home/services/ynab
mkdir -p /home/services/KidAI
mkdir -p /home/services/reforma
mkdir -p /home/services/backups

# 9. Generate GitHub Actions deploy SSH keypair
ssh-keygen -t ed25519 -C "github-actions-deploy@hetzner-vps" -f /root/.ssh/github_actions_deploy -N ""
# Add public key to authorized_keys
cat /root/.ssh/github_actions_deploy.pub >> /root/.ssh/authorized_keys
chmod 600 /root/.ssh/authorized_keys

# 10. Print private key for GitHub Actions secret storage
echo "=== PRIVATE KEY (store as HETZNER_SSH_KEY in GitHub repo secrets) ==="
cat /root/.ssh/github_actions_deploy
echo "=== END PRIVATE KEY ==="
```

After running, capture and store the private key output — it will be needed for Plans 02-07 GitHub Actions secrets.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local host → Hetzner VPS | SSH tunnel; commands execute as root on remote machine |
| .env.production → Docker Compose | File contains plaintext secrets; must never be committed or world-readable |
| GitHub Actions → VPS | SSH action using private key stored as encrypted GitHub secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-62-01 | Disclosure | /home/services/.env.production | mitigate | chmod 600; file never committed to git; excluded from all .gitignore'd paths |
| T-62-02 | Disclosure | GitHub Actions SSH private key | mitigate | Store as masked GitHub Actions secret (HETZNER_SSH_KEY); never echo in workflow steps |
| T-62-03 | Elevation | root SSH access to VPS | mitigate | SSH key-only auth (no password); disable password auth in /etc/ssh/sshd_config: `PasswordAuthentication no` |
| T-62-04 | Spoofing | POSTGRES_PASSWORD weak entropy | mitigate | Generate with `openssl rand -base64 32` (256-bit entropy); stored only in .env.production (600) |
| T-62-05 | Tampering | Docker base images from Docker Hub | mitigate | Use official pinned tags (node:20-alpine, postgres:16-alpine); `--build` on every deploy prevents stale cache |
| T-62-06 | Denial of Service | VPS exposed ports | mitigate | Close all ports except 22 (SSH); Cloudflare Tunnel handles 80/443 routing; configure ufw: `ufw allow 22 && ufw enable` |
</threat_model>
