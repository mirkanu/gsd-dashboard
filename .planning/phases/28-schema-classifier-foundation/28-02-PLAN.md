From 28-RESEARCH.md (PATTERNS - priority ordered, first match wins):
```javascript
// Hidden: tool calls
/^(?:Read|Write|Edit|Bash|Grep|Glob|WebSearch|WebFetch|TodoWrite)\(/
/^(?:mcp__|antml_)/
/^\s*\d+\s*\|/          // numbered code output lines

// Stage banners
/^#{1,3}\s+Phase\s+\d+/i
/^(?:PLAN|EXECUTE|RESEARCH|VERIFY):/i
/^={3,}\s+/

// Errors
/^(?:Error|ERROR|FAILED|TypeError|SyntaxError|ReferenceError):/
/npm ERR!/
/ENOENT|EACCES|ECONNREFUSED/

// Completions
/PHASE COMPLETE/i
/All (?:plans|tasks) (?:executed|finished|complete)/i
/SUMMARY\.md written/i

// Checkpoints
/YOUR ACTION:/i
/Checkpoint:/i
/VERIFY:/i

// Hidden: working/thinking
/\(\s*\d+[ms]+\s*\xB7\s*\u2193/   // timer patterns
/\(\s*thinking\s*\)/
/^\s*Reading\s+/
/^\s*Writing\s+/
/^\s*Searching\s+/
```

   a. **MESSAGE_TYPES** constant object (exported):
      - STAGE_BANNER, CHECKPOINT, COMPLETION, ERROR, HIDDEN, TEXT

   b. **PATTERNS** array (priority-ordered, first match wins):
      Each entry: `{ type: string, patterns: RegExp[] }`
      Order matters -- hidden tool calls first (highest priority), then stage banners, errors, completions, checkpoints, hidden working/thinking. TEXT is the fallback (not in patterns array).
      
      Use patterns from the research PATTERNS list. Key additions beyond research:
      - Hidden: also match `Edit(`, `Search(`, `Agent(`, `WebSearch(`, `WebFetch(`
      - Hidden: numbered code lines `^\s*\d+\s*\|`
      - Hidden: `antml_invoke`, `antml_function`, `mcp__`

      - Errors: also match `FATAL:`, `Unhandled`, `reject`
      
   c. **classifyLine(rawLine)** function (exported):
      - Strip ANSI with strip-ansi (require('strip-ansi'))
      - Trim whitespace
      - If empty/whitespace-only after strip, return null
      - Iterate PATTERNS in order, test each regex, return first match as `{ msg_type, content: cleanLine, metadata: null }`
      - If no match, return `{ msg_type: 'text', content: cleanLine, metadata: null }`
      
   d. **classifyChunks(rawText)** function (exported):
      - Split rawText by newlines
      - Call classifyLine on each
      - Filter out nulls (empty lines)
      - Return array of `{ msg_type, content, metadata }` objects
