Create `client/src/hooks/useResizableColumns.ts` exporting `useResizableColumns`.

**Storage key:** `"gsd-column-widths"` in localStorage. Value: JSON array `[leftPct, middlePct, rightPct]` — all numbers, must sum to 100.

**Default widths:** `[20, 50, 30]` (left 20%, middle 50%, right 30%). Note: the current middle column uses `1fr` which approximates 50% given the left+right totals.

**Hook signature:**
```ts
interface ColumnWidths { left: number; middle: number; right: number }
interface UseResizableColumnsReturn {
  widths: ColumnWidths;
  startDragLeft: (e: React.MouseEvent) => void;   // handle between left and middle
  startDragRight: (e: React.MouseEvent) => void;  // handle between middle and right
  isDragging: boolean;
}
function useResizableColumns(): UseResizableColumnsReturn
```

**Drag logic:**
- On `startDragLeft` mousedown: record `startX = e.clientX` and `startWidths = widths`
- On `mousemove` (attached to `document`): compute `deltaPct = (e.clientX - startX) / containerWidth * 100`
  - `newLeft = clamp(startWidths.left + deltaPct, 12, 35)`
  - `newMiddle = startWidths.middle - (newLeft - startWidths.left)` — middle absorbs the change
  - If `newMiddle < 20`: clamp middle at 20 and stop adjusting left
- On `startDragRight` mousedown: same pattern but adjusts middle and right
  - `newRight = clamp(startWidths.right - deltaPct, 15, 45)`
  - `newMiddle = startWidths.middle + (startWidths.right - newRight)`
- On `mouseup`: save to localStorage, set `isDragging=false`, remove event listeners
- Container width: use `document.documentElement.clientWidth` minus the sidebar width. Since we don't have easy access to the exact container ref from the hook, use the full viewport width as an approximation — close enough for drag feel.

**Persistence:** Load from localStorage on mount. On save, store `[left, middle, right]` as JSON. Skip saving if values are invalid (NaN, sum != 100 ±1).

**Cleanup:** Remove document mousemove/mouseup listeners on unmount.

Write tests in `client/src/hooks/__tests__/useResizableColumns.test.ts` using vitest + @testing-library/react `renderHook`.
