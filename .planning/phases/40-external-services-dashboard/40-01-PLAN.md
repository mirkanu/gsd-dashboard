Create `server/routes/services.js` with a single `GET /` route (mounted at `/api/services`).

**gsd-projects.json** — add a `services` array to each project (except archived ones). Use this exact structure:

```json
"services": [
  { "name": "Railway", "statusUrl": "https://railway.instatus.com/api/v2/status.json" },
  { "name": "GitHub", "statusUrl": "https://www.githubstatus.com/api/v2/status.json" },
  { "name": "Claude", "statusUrl": "https://status.anthropic.com/api/v2/status.json" },
  { "name": "OpenAI", "statusUrl": "https://status.openai.com/api/v2/status.json" }
]
```

For `gsddashboard` and `debates` projects also include:
```json
{ "name": "Vercel", "statusUrl": "https://www.vercel-status.com/api/v2/status.json" }
```

For any project using email (none currently), Resend status would be `https://status.resend.com/api/v2/status.json` — omit for now.

**server/routes/services.js** implementation:
- Read `gsd-projects.json` fresh on each request (no caching needed — external fetches dominate latency)
- Collect all unique `statusUrl` values across all non-archived projects
- Fetch all URLs in parallel using `Promise.allSettled` with `AbortSignal.timeout(5000)` per request
- Normalize each response to `{ name, statusUrl, status, description }` where `status` is one of: `"operational" | "degraded" | "outage" | "unknown"`
- Normalization logic:
  - Atlassian format: `indicator === "none"` → `"operational"`, `"minor"` → `"degraded"`, `"major" | "critical"` → `"outage"`, fetch error or parse error → `"unknown"`
  - If the JSON has a top-level `status` string field (Railway instatus format may vary) — map `"operational"` → `"operational"`, anything else → `"degraded"`
- Return shape:
  ```json
  {
    "projects": [
      {
        "name": "josie",
        "services": [
          { "name": "Railway", "status": "operational", "description": "All Systems Operational" },
          { "name": "GitHub", "status": "operational", "description": "All Systems Operational" }
        ]
      }
    ]
  }
  ```
- Include archived projects in the response only if they have services defined; skip projects with no `services` field.

**server/index.js** — add after the existing router registrations:
```javascript
const servicesRouter = require("./routes/services");
app.use("/api/services", servicesRouter);
```
