**types.ts** — Add interfaces:
```typescript
export interface ProjectSettings {
  project_key: string;
  verbosity: 'verbose' | 'normal' | 'quiet';
  telegram_alerts: Record&lt;string, boolean&gt;;
  updated_at?: string;
}

export interface ClaudeMdResponse {
  content: string;
  path: string;
}
```

**api.ts** — Add a `config` namespace to the exported `api` object:
```typescript
config: {
  getClaudeMd: (project: string) =>
    request&lt;ClaudeMdResponse&gt;(`/config/claude-md?project=${encodeURIComponent(project)}`),
  saveClaudeMd: (project: string, content: string) =>
    request&lt;{ ok: boolean }&gt;('/config/claude-md', {
      method: 'PUT',
      body: JSON.stringify({ project, content }),
    }),
  getProjectSettings: (project: string) =>
    request&lt;ProjectSettings&gt;(`/config/project-settings/${encodeURIComponent(project)}`),
  saveProjectSettings: (project: string, settings: Partial&lt;ProjectSettings&gt;) =>
    request&lt;{ ok: boolean; settings: ProjectSettings }&gt;(
      `/config/project-settings/${encodeURIComponent(project)}`,
      { method: 'PUT', body: JSON.stringify(settings) },
    ),
  listProjectSettings: () => request&lt;ProjectSettings[]&gt;('/config/project-settings'),
},
```

**ConfigPage.tsx** — Create the configuration page with these sections:

1. **Project selector** (top): Tabs or dropdown listing "Global" + all project names from the existing `/api/gsd/projects` endpoint. Default to "Global".

2. **CLAUDE.md Editor** (main section):
   - Fetch CLAUDE.md content when project selection changes using `api.config.getClaudeMd(selectedProject)`
   - Display in a `textarea` with monospace font, full width, ~20 rows height
   - Show the file path (read-only) above the textarea
   - "Save" button below the textarea — calls `api.config.saveClaudeMd`
   - Show success/error feedback via a toast or inline message
   - Show a loading skeleton while fetching content
   - Handle 404 gracefully — show "No CLAUDE.md found at {path}" message with option to create it

3. **Verbosity Setting** (below editor, only for non-global projects):
   - Label: "Claude Session Verbosity"
   - A select dropdown with options: verbose, normal, quiet
   - Fetch current setting from `api.config.getProjectSettings(selectedProject)` when project changes
   - Auto-save on change (call `api.config.saveProjectSettings` immediately)
   - Show saved confirmation briefly

4. **Telegram Notification Toggles** (below verbosity, only for non-global projects):
   - Label: "Telegram Alerts"
   - Toggle switches for each alert type:
     - `state_change`: "Session state changes" (active/paused/completed)
     - `error`: "Error notifications"
     - `completion`: "Session completed"
     - `waiting_input`: "Waiting for input"
   - Auto-save on toggle change
   - If Telegram is not configured (env vars missing), show a muted note: "Telegram not configured — set TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID"

Use Tailwind classes consistent with existing pages. Use lucide-react icons: `FileText` for CLAUDE.md, `Volume2` for verbosity, `Bell` for notifications, `Settings2` or `Wrench` for the page header.

**Sidebar.tsx** — Add a "Config" nav entry with a `Settings2` or `Wrench` icon, linking to `/config`. Place it after the existing "Usage" entry.

**App.tsx** — Add route: `Route path="config" element={ConfigPage}` inside the Layout route group. Add the import for ConfigPage.

Follow existing patterns:
