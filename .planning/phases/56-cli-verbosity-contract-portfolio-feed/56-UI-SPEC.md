## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), badge internal padding |
| sm | 8px | Compact element spacing (`gap-2`, `px-2`, `py-2`) |
| md | 16px | Default element spacing (`px-4`, `py-3`, `gap-3`) |
| lg | 24px | Section padding (`p-4` on cards = 16px, `space-y-3`) |
| xl | 32px | Layout gaps (`mb-4`, `space-y-4`) |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (not used in these components) |

Exceptions: Feed row items use `px-4 py-3` (12px vertical, 16px horizontal) — matches existing "Recent Activity" row rhythm exactly. Touch targets for toggle switches: 20px height (`h-5`) at 36px width (`w-9`) — acceptable for desktop-only dashboard.

Source: `Dashboard.tsx` lines 289–314, `ConfigPage.tsx` Toggle component lines 44–78.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--surface-1: #0c0c14` | Page background |
| Secondary (30%) | `--surface-2: #13131e` / `--surface-3: #1a1a28` | Cards (`bg-surface-2 border border-border rounded-xl`), hover states (`bg-surface-4: #222233`) |
| Accent (10%) | `#6366f1` (indigo-500) | Toggle thumb active state, focus rings, "View All" link hover |
| Destructive | `text-red-400` | Error messages only (no destructive actions in this phase) |

Accent reserved for:
- Toggle switch background when `checked=true` (`bg-accent`)
- Focus ring on interactive elements (`focus:ring-accent/30`)
- "View All →" button on hover (`btn-ghost` class applies `hover:text-gray-200`)

Note: Feed entry rows use `hover:bg-surface-4` (same as existing "Recent Activity" rows) — accent is NOT used for row hover.

Event type color coding for feed entries:
- Plan complete: `bg-emerald-500/10 text-emerald-400 border-emerald-500/20` (success)
- Verify passed: `bg-emerald-500/10 text-emerald-400 border-emerald-500/20` (success)
- Verify failed: `bg-red-500/10 text-red-400 border-red-500/20` (failure)
- Waiting for input: `bg-amber-500/10 text-amber-400 border-amber-500/20` (attention)
- Phase complete: `bg-purple-500/10 text-purple-400 border-purple-500/20` (milestone)

These follow the existing `badge` utility class pattern: `bg-*/10 text-* border-*/20`.

Source: `index.css` `.badge` class definition, `StatusBadge.tsx` for color pattern reference.

## Component Specifications

### 1. Dashboard Card — Portfolio Feed Preview

**Replaces:** "Recent Activity" section (`Dashboard.tsx` lines 273–317)

**Structure:**
```
[Section header row]
  "Portfolio Feed"                          "View All →"
[Card body — divide-y divide-border]
  [row] [EventTypeBadge] [entry text]  [timeAgo]
  [row] [EventTypeBadge] [entry text]  [timeAgo]
  ... (max 5 entries)
[Empty state — if no entries]
```

**Header row:** `flex items-center justify-between mb-4`
- Heading: `text-sm font-semibold text-gray-300` — label "Portfolio Feed"
- "View All →" button: `btn-ghost text-xs` — navigates to `/feed` — label "View All →" with `ArrowRight` icon (`w-3 h-3`)

**Card container:** `card divide-y divide-border` (existing `.card` utility = `bg-surface-3 border border-border rounded-xl`)

**Feed row:** `px-4 py-3 flex items-center gap-3 hover:bg-surface-4 transition-colors`
- Left: `EventTypeBadge` (see below) — `flex-shrink-0`
- Middle: `text-sm text-gray-300 truncate flex-1` — plain-English entry string
- Right: `text-[11px] text-gray-600 flex-shrink-0` — relative timestamp (e.g. "2m ago")

**Empty state:** Use existing `<EmptyState>` component
- Icon: `Activity`
- Title: "No events yet"
- Description: "Landmark events from GSD sessions will appear here."

**Max entries on Dashboard preview:** 5 (down from 8 in old Recent Activity — feed events are higher signal)

**Location:** Add a new card section to `ConfigPage.tsx` between "Claude Session Verbosity" and "Telegram Alerts" sections.


- Title: `text-sm font-semibold text-gray-200`
- Saved indicator: `flex items-center gap-1 text-emerald-400 text-xs ml-auto` with `<Check w-3 h-3 />` + "Saved" — same pattern as "Claude Session Verbosity" saved state

**Scope note below title:** `text-xs text-gray-500` — "Per-project only. Has no effect on the Global tab."
- Only render the toggles when a non-global project is selected (`!isGlobal`)
- When `isGlobal`: render `text-sm text-gray-500 italic` — "Select a project to configure GSD verbosity overrides."

**Toggles (use existing `<Toggle>` component):**

Toggle 1:
- `checked`: `settings?.suppress_context_reask ?? false`
- `label`: "Skip CONTEXT.md re-asking when file already exists"
- Helper text below: `text-xs text-gray-600 mt-1` — "When on, GSD skips the discuss-phase interview if CONTEXT.md is already present."

Toggle 2:
- `checked`: `settings?.suppress_plan_ceremony ?? false`
- `label`: "Suppress plan preamble and postamble narration"
- Helper text below: `text-xs text-gray-600 mt-1` — "When on, GSD omits the opening and closing narration around each plan execution."

```
<div className="space-y-1">
  <Toggle checked={...} onChange={...} label="..." />
  <p className="text-xs text-gray-600 pl-0">Helper text here.</p>
</div>
```

Both toggles default to `false` (off). Saving: each toggle auto-saves on change, following existing `handleAlertToggle` pattern with per-key `settingsSaved` feedback.

## Interaction States

### Feed rows
- Default: `text-gray-300` entry text
- Hover: `hover:bg-surface-4 transition-colors` — applies to both Dashboard preview and full feed rows
- No click action on full `/feed` page rows (they are not navigable — no session detail for in-memory events)
- Dashboard preview rows: no click action (in-memory events have no session_id to navigate to)

### Toggles
- Off: `bg-surface-3` track, thumb at `translate-x-0.5`
- On: `bg-accent` track, thumb at `translate-x-4`
- Disabled: `opacity-50 cursor-not-allowed` (apply during save in-flight)
- Auto-save on change: fire PUT immediately, show "Saved" indicator for 2s then hide (matches existing pattern)

### "View All →" button
- Normal: `btn-ghost text-xs` — `text-gray-400 hover:text-gray-200 hover:bg-surface-4`
- No loading state — navigates immediately

### Sidebar nav entry
- Active: existing NavLink active class (indigo accent left border or background highlight — matches other `PRIMARY_ITEMS` entries)
- Icon: `Rss` from lucide-react — same `w-4 h-4` sizing as other nav icons
