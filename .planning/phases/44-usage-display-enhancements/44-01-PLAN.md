Modify the `GET /api/pricing/window` handler in server/routes/pricing.js.

1. Introduce a helper inside the handler (or as a top-level const) called `summarizeWindow(tokenRows, rules)` that:
   - Calls `calculateCost(tokenRows, rules)` to get total_cost + breakdown.
   - Sums input_tokens/output_tokens/cache_read_tokens/cache_write_tokens across tokenRows.
   - Builds a `by_model` array by mapping each breakdown entry to:
     ```
     {
       model: row.model,
       model_pattern: row.matched_rule,
       display_name: rules.find(r => r.model_pattern === row.matched_rule)?.display_name || row.model,
       cost: row.cost,
       input_tokens: row.input_tokens,
       output_tokens: row.output_tokens,
       cache_read_tokens: row.cache_read_tokens,
       cache_write_tokens: row.cache_write_tokens,
     }
     ```
   - Sorts by_model by cost descending.
   - Returns `{ total_cost, input_tokens, output_tokens, cache_read_tokens, cache_write_tokens, by_model }`.

2. Replace the current daily/weekly cost calculation with:
   ```
   const dailySummary = summarizeWindow(tokensForWindow(todayMidnight), rules);
   const weeklySummary = summarizeWindow(tokensForWindow(weekStart), rules);
   ```

3. Update the JSON response:
   ```js
   res.json({
     daily: {
       cost: dailySummary.total_cost,

       cache_write_tokens: dailySummary.cache_write_tokens,
   ```
