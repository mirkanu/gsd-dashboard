<task type="auto">
  <name>Task 1: Build TmuxClassifier polling loop and wire into server</name>
  <files>server/gsd/classifier.js, server/index.js</files>
  <action>
Create server/gsd/classifier.js with a TmuxClassifier class that:

1. Constructor takes (stmts, broadcast) where stmts is the prepared statements object from db.js and broadcast is the WebSocket broadcast function.

2. Has a `snapshots` Map storing previous capture-pane lines per project name.

3. `poll(projectName, tmuxSession)` method:
   - Calls `capturePaneText(tmuxSession)` from `require('./tmux')` to get current pane text
   - If null/empty, return
   - Split into lines, compare with stored snapshot for this project
   - Use `diffLines(prevLines, currentLines)` to find new content
   - If no new content, return
   - Update snapshot
   - Call `classifyChunks(newContent)` from `require('./classifierPatterns')`
   - Filter out hidden messages (msg_type === 'hidden')
   - For each visible chunk, persist via `stmts.insertClassifiedMessage.run(projectName, 'inbound', chunk.content, chunk.msg_type, chunk.metadata ? JSON.stringify(chunk.metadata) : null)`
   - Broadcast each persisted message: `broadcast('gsd_chat_message', { project: projectName, message: { id: lastInsertRowid, project: projectName, direction: 'inbound', content: chunk.content, message_type: chunk.msg_type, metadata: chunk.metadata, created_at: new Date().toISOString() } })`
   - Note: insertClassifiedMessage does NOT use RETURNING * (check db.js -- it does not). Use `db.prepare(...).run()` which returns `{ lastInsertRowid }`. Access this via the statement info object.

4. `diffLines(prevLines, currentLines)` method:
   - If prevLines is empty, return all currentLines joined
   - Find the last line of prevLines in currentLines by walking backward
   - Verify match with 2-3 preceding lines for confidence
   - Return lines after the overlap point joined with newlines
   - If no overlap found (fast scroll), return all current lines
   - If no new lines after overlap, return null

5. `groupConsecutiveText(chunks)` method:
   - Group consecutive chunks with the same msg_type === 'text' into a single text message
   - Stage banners, errors, checkpoints, completions always break groups
   - Return grouped array

Wire into server/index.js:
- After the existing maintenance setInterval (around line 139), add a new setInterval at 2500ms
- Import TmuxClassifier, stmts from db.js, broadcast from websocket.js, loadConfig and isTmuxSessionActive from gsd/tmux.js
- In the interval callback: load projects from config, iterate, skip archived/paused/non-tmuxActive projects, call classifier.poll() for each
- Wrap each poll call in try/catch to prevent one project's error from blocking others
- Log errors to console.error with project name

IMPORTANT: The stmts.insertClassifiedMessage uses .run() not .get() -- it returns a RunResult with `changes` and `lastInsertRowid`. Use `lastInsertRowid` for the broadcast message id.
