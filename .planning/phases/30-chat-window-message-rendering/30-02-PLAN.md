   - Pattern from research: `<div className="flex items-center gap-3 py-3 px-4"><div className="flex-1 h-px bg-border" /><span className="text-xs font-semibold text-accent uppercase tracking-wide">{content}</span><div className="flex-1 h-px bg-border" /></div>`

2. **CheckpointPrompt.tsx** (MSG-03): Amber-bordered card with optional tappable buttons.
   - Props: `{ content: string; metadata?: Record<string, unknown> | null; onAction?: (text: string) => void }`
   - Extract options from metadata: `(metadata?.options as string[]) || []`
   - Also parse numbered options from content if metadata has none: scan for lines matching `/^\s*(\d+)[.)]\s+(.+)/` and extract as options
   - Render: amber-bordered card with content text. If options exist, render each as a tappable button that calls `onAction(String(index + 1))`
   - Button styling: `text-left px-3 py-1.5 rounded border border-amber-400/20 bg-amber-400/5 text-sm text-amber-300 hover:bg-amber-400/10 active:scale-[0.98] transition-all`
   - Card container: `mx-4 my-1 p-3 rounded-lg border border-amber-400/30 bg-amber-400/5`

3. **CompletionCard.tsx** (MSG-05): Green-tinted success summary.
   - Props: `{ content: string }`
   - Render: card with emerald/green border and tint, content as text
   - Container: `mx-4 my-1 p-3 rounded-lg border border-emerald-500/30 bg-emerald-500/5`
   - Text: `text-sm text-emerald-300` with a check icon (lucide CheckCircle)

4. **ErrorCard.tsx** (MSG-06): Red-bordered with collapsible long content.
   - Props: `{ content: string }`
   - State: expanded (boolean, default false)
   - Split content by newlines. Show first 3 lines as preview. If >3 lines, show expand/collapse button.
   - Container: `mx-4 my-1 p-3 rounded-lg border border-red-500/30 bg-red-500/5`
   - Text: `text-xs text-red-400 whitespace-pre-wrap font-mono`
   - Expand button: `text-[10px] text-red-400/60 hover:text-red-400`

5. **CommandChips.tsx** (MSG-04): Tappable GSD command suggestion chips.
   - Props: `{ commands: string[]; onSelect: (cmd: string) => void }`
   - Render: horizontal flex wrap of pill-shaped buttons
   - Each chip: `px-3 py-1 rounded-full border border-accent/20 bg-accent/5 text-xs text-accent hover:bg-accent/10 active:scale-[0.98] transition-all`
   - When clicked, call onSelect with the command text

6. **ChatMessageRenderer.tsx**: Switch-on-type dispatcher.
   - Props: `{ msg: GsdMessage; onAction?: (text: string) => void }`
   - Switch on `msg.message_type`:
     - 'stage_banner' -> `<StageBanner content={msg.content} />`
     - 'checkpoint' -> `<CheckpointPrompt content={msg.content} metadata={msg.metadata} onAction={onAction} />`
     - 'completion' -> `<CompletionCard content={msg.content} />`
     - 'error' -> `<ErrorCard content={msg.content} />`
     - 'text' with direction 'outbound' -> chatscope `<Message model={{ message: msg.content, direction: 'outgoing', position: 'single' }} />`
     - 'text' with direction 'inbound' -> chatscope `<Message model={{ message: msg.content, direction: 'incoming', position: 'single' }} />`
     - default -> incoming message
   - Import Message from @chatscope/chat-ui-kit-react
