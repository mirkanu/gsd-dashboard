# Phase 50.5 Plan 01: Client Route + View Deletions Summary

Removed dormant upstream-fork client surface area: deleted Sessions/SessionDetail/ActivityFeed views and the old agent-specific KanbanBoard page, relocated KanbanBoard as a generic reusable board primitive, stripped the browser-notifications hook + Settings section. All removed routes redirect to `/` so bookmarks do not 404. Scope: client/ only — no server changes.

## Files Created

- `client/src/components/board/KanbanBoard.tsx` — Generic `<KanbanBoard items columns onMove renderCard />` primitive. Contract:
  - `BoardColumn { id; title }` and `BoardItem { id; columnId }` exported types
  - Generic `<T extends BoardItem>` over items
  - Optional `onMove(itemId, toColumnId)` fired from native HTML5 drop
  - Optional `renderCard(item)` with a default card fallback
  - No agent-specific state, no WebSocket, no API coupling
- `client/src/components/board/__tests__/KanbanBoard.test.tsx` — 4 tests covering column render, item-by-column placement, `onMove` drop callback, custom `renderCard` override.
