### Rationale for KEEP Decisions

The audit found that both routes and all three candidate tables have **active, ongoing use** in the current codebase:

1. **agents/events routes** are explicitly exposed via MCP tools that Claude Code sessions call to inspect agent state and session transcripts
2. **agents table** is written to on every tool call (hook ingestion) and read by session detail, compaction import
3. **events table** is the core transcript ledger — written to on every hook event, read for session history and stats
4. **token_usage table** is actively consumed by analytics, pricing, and project metadata calculation

Deleting any of these would:
- Break MCP tool surface (agents-tools, event-tools, observability-tools)
- Lose audit trail (events)
- Lose cost tracking (token_usage)
- Break session-detail and project metadata (both)
